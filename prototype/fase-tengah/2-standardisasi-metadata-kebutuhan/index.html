Penilaian 4 Prinsip Satu Data (SDI)

4 Pilar Kepatuhan Perwal SDI:
  • 1. Standar Data: Definisi operasional & satuan baku terverifikasi.
  • 2. Metadata Baku: Terdaftar dalam Katalog Metadata Daerah.
  • 3. Interoperabilitas: Format REST API JSON/GeoJSON terbuka via SPLP.
  • 4. Kode Referensi: Terhubung ke Kode Induk Pemkot (Dukcapil/BPKAD/BKPSDM).
